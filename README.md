# Intelligent Support Assistant

An AI-powered customer support assistant built with RAG and agent-based workflows.

## Project Goal

The goal is to build a support system that can answer documentation-based questions, retrieve business information, and use tools when necessary.

## Planned Capabilities

- Answer questions using technical documentation.
- Retrieve business information from a database.
- Select between document retrieval and business tools.
- Provide sources for knowledge-based answers.
- Evaluate retrieval quality and analyze failures.
- Expose the system through an API.
- Support containerized deployment and automated testing.
